# 智慧养老服务中心

课程团队项目；项目负责人 / 维护者：迟凡杰

本仓库是课程团队项目的私有源码备份快照，集中保存前端与后端的当前可归档版本。项目由课程团队协作完成，负责人信息不表示个人独立完成。

## 目录结构

- `frontend/`：Vue、TypeScript 与 Vite 前端源码。
- `backend/`：Spring Boot 后端源码，以及经过脱敏的数据库结构和示例配置。

## 配置说明

仓库不包含真实数据库账号、邮箱凭据、JWT 密钥、上传目录或生产环境配置。启动前请参考前后端目录中的示例文件，通过环境变量提供本地配置。
