# 智慧养老服务中心前端

课程团队项目；项目负责人 / 维护者：迟凡杰

本仓库保存课程团队协作完成的前端源码，由六人课程团队共同参与；负责人信息不表示个人独立完成。功能导航、架构和本地准备步骤见 [仓库首页](../README.md)。

## 安全归档说明

- 后端地址仅通过 `VITE_API_BASE_URL` 配置；`.env.example` 使用相对路径 `/api`，真实环境文件不入库。
- 语音合成功能保留兼容接口，但当前为禁用的后端代理占位实现，不包含应用标识、密钥、签名或直连逻辑。
- `src/stores/temp/` 中的数据只保留原有对象结构，值均为明显的合成占位数据。
- 未经许可审查的图片、媒体、映射、可执行文件、WASM、证书、日志、缓存和构建产物均不纳入当前归档。
- `package.json` 与 `pnpm-lock.yaml` 仅作为未验证的依赖声明保存；本次归档未安装依赖，也未执行项目、测试或构建。
